## Evidence meanings

- APPLIED_RECORDED means the exact version string is present in the target native history. It does not prove the local SQL bytes were used or every effect persists.
- VERIFIED catalogue means selected metadata was observed and integrity checked. Complete function bodies, full migration SQL contents, platform security details and exhaustive role inheritance were not collected.
- UNRESOLVED_BYTES is retained where no target checksum/original deployment artifact establishes byte provenance. Object similarity is not byte identity.
- PENDING means no matching native history row and no approved executable forward package; it is not permission to run a draft.
- MUTUALLY_EXCLUSIVE variants are never sequential migrations. Divergent local hashes prove different artifacts, not target corruption. No target migration is newly labelled DIVERGENT without evidence.
- SUPERSEDED applies to initial/metadata/recovery collection commands and obsolete P3/old deployment plans as current execution instructions. No 0009 SQL candidate is declared superseded on the target without provenance. Historical artifacts remain intact.
